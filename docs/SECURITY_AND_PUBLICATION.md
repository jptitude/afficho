# Before publishing this repository

- Inspect exported Python and `.desktop` files for passwords, tokens, private email addresses, absolute paths and personal identifiers.
- Do not publish a raw microSD image, live system configuration, private logs or personally identifying screenshots.
- Do not publish MP3/WAV files or third-party promotional images without rights to redistribute.
- Check the actual import directory and startup file against the code before claiming that install instructions are universal.
- Decide on a license before granting reuse permissions. Public visibility alone does not equal open source.
- Consider adding a short on-device demo and an architecture photo only after checking that they reveal no personal information.
