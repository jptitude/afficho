# AFFICHO — Présentation en français

**AFFICHO** est un lecteur d'affichage numérique hors ligne conçu en Python pour Raspberry Pi. Il transforme un écran HDMI en support de communication autonome.

## Fonctionnalités validées

- Images PNG Full HD 1920 × 1080 en boucle.
- Ordre personnalisé des images et durée individuelle configurable.
- Signature facultative sur chaque image.
- Musique d'ambiance MP3 ou WAV en boucle.
- Import sécurisé d'une campagne depuis la partition `bootfs`.
- Démarrage automatique sans clavier ni souris.

**Plateforme testée :** Raspberry Pi Zero Rev 1.3 sous Raspberry Pi OS Bookworm.  
**État :** MVP technique v1.2.0, démontrable, non qualifié pour une commercialisation à grande échelle.

Les vidéos ne sont pas encore prises en charge. L'actualisation des contenus se fait par microSD depuis un PC. Le projet documente également une démarche de dépannage, d'intégration Linux, de tests sur matériel réel et de sauvegarde.

Voir `README.md` pour la présentation complète en anglais et les exemples de configuration.
